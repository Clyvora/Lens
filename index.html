Private JSON and CSV viewer, inspector, and converter.

Clyvora Lens lets you open, inspect, search, filter, sort, and convert structured data locally in your browser. Selected JSON and CSV files never leave your device.

JSON and CSV tools

  • Explore JSON as a collapsible tree or formatted text.
  • Search JSON keys and values and copy paths or subtrees.
  • Search, filter, profile, and sort CSV rows.
  • Convert JSON to CSV or CSV to JSON with configurable options.
  • Process large files away from the main browser interface.
